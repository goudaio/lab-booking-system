# 实验室设备预约系统

纯前端 Web 应用，用于实验室设备的预约、使用管理和信誉评分，无需后端，数据存储在浏览器 localStorage。

## 技术栈

- HTML + CSS + JavaScript（无框架、无依赖）
- localStorage 数据持久化
- 响应式 UI 设计

## 功能清单

### 登录与权限
- 区分管理员 / 研究员两种角色
- 不同角色看到不同的导航菜单和功能页面

### 设备管理
- 18 台实验设备，按学科分类（物理学、化学、生物学、材料科学）
- 设备状态：可预约、使用中、维修中、已停用
- 支持按名称/型号搜索，按学科、分类、状态筛选
- 管理员可随时结束维修、停用设备、启用设备

### 预约系统
- 选择日期（未来14天）、时间段（可多选）、同行人员、用途
- **预约冲突检测**：同设备同日期同时段不可重复预约
- 信誉分 ≥ 60 的研究员预约自动通过，无需审核
- 信誉分 < 60 的研究员无法预约，引导至申诉页面
- 可取消预约（已确认预约取消扣5分爽约）
- 可完成使用（按时完成 +5分，超时使用 -10分）

### 智能推荐 ⭐
- 目标时段已被占用时，自动推荐**同类别/同学科且同时段空闲**的替代设备
- 同时给出本设备未来 14 天内**最近的可用日期**
- 推荐结果可一键切换：点标签即可跳到该设备或该日期继续预约
- 纯规则实现，不联网、不调用任何外部服务，**离线可用**

### 信誉评分系统
- 满分 100 分，低于 60 分禁止预约
- 扣分规则：超时 -10、爽约 -5
- 加分规则：按时完成 +5
- 信誉变动记录最多保留 10 条
- 仪表盘展示信誉分进度条和状态

### 申诉系统
- 信誉 < 60 分且无待处理申诉时可提交申诉（每天限1次）
- 管理员在"待审批申请"页面审核：通过 / 拒绝
- 通过后信誉分恢复至 60 分
- 拒绝须填写原因，原因以通知形式推送到研究员收信箱

### 报修系统
- 研究员在设备列表或预约页面点击"报修"按钮
- 提交报修后设备自动转为"维修中"，其他人无法预约
- 报修信息进入管理员收信箱
- 管理员处理报修：已修复 / 无法修复
- 已修复 → 设备恢复可用，通知报修人
- 无法修复 → 设备停用，通知报修人

### 数据导出与迁移（管理员）
- 导出全量数据备份（JSON），可在任意浏览器一键导入还原
- 导出预约明细 CSV，带 UTF-8 BOM，**Excel 双击打开中文不乱码**
- 让成果可被其他实验室直接接管复用

### 设备统计（管理员）
- 查看各设备在不同时间段的访问次数（当天/近三天/近一周/近一个月）
- 设备访问排行
- 单设备最近预约记录

### 使用情况（研究员）
- 各时间段预约统计
- 信誉分详情与变动记录
- 设备使用频次排行
- 我的预约记录

### 定时任务
- 每 60 秒自动检查超时预约
- 超时预约自动标记为"已超时"并扣 10 分

### 收信箱
- **管理员**：报修处理（待处理 + 已处理历史）、申诉列表
- **研究员**：通知消息、申诉记录、报修记录
- 导航栏显示未读/待处理数量徽章

## 代码质量

以下缺陷已修复并通过 35 项自动化冒烟测试：

| 问题 | 说明 | 修复方式 |
|------|------|---------|
| 时区错位 | 原先用 `toISOString()` 生成/比较日期，取的是 UTC 日期。UTC+8 下每日 00:00–08:00 会把「今天」算成前一天，导致统计口径整体偏移一天 | 新增 `Store._dateStr()` / `Store.todayStr()`，全部改用浏览器本地时区格式化 |
| XSS 注入 | 页面统一用 `innerHTML` 拼接，「用途 / 报修描述 / 申诉理由」等用户输入未转义 | 新增 `App.esc()`，在所有用户输入插值点转义后再渲染 |
| 输入无限制 | 文本字段缺少长度约束 | 新增 `TEXT_LIMITS` 校验 + 表单 `maxlength`，关键字段必填 |

> 冒烟测试覆盖：种子数据、本地时区、XSS 转义、登录鉴权、预约冲突、信誉分钳制、报修闭环、申诉闭环、智能推荐、CSV 转义。

## 本地运行

直接用浏览器打开 `index.html` 即可。

## 部署到华为云 OBS

1. 创建 OBS 桶，权限设为"公共读"
2. 上传 `index.html`、`css/style.css`、`js/store.js`、`js/app.js`（保持目录结构）
3. 配置静态网站托管，默认首页设为 `index.html`
4. 修改各文件 Content-Type：`.html` → `text/html`、`.css` → `text/css`、`.js` → `application/javascript`
5. 访问 `https://{桶名}.obs-website.{区域}.myhuaweicloud.com`

## 数据说明

所有数据存储在浏览器 localStorage，包含以下键：

| Key | 说明 |
|-----|------|
| lab_devices | 设备列表 |
| lab_bookings | 预约记录 |
| lab_accounts | 账户信息 |
| lab_session | 当前登录会话 |
| lab_credit | 信誉评分数据 |
| lab_messages | 消息（申诉、通知、报修） |

清除浏览器 localStorage 可重置所有数据。
